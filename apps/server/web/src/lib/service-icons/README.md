# Local service icons

These icons are bundled with the Shumoku web app. Selecting one copies its SVG
data URI into a block's operator layout. User-uploaded SVG, PNG, JPEG, WebP and
ICO files are likewise saved as data URIs in the local Shumoku database, rather
than referenced from the original web address.

`apache.svg`, `cloudflare.svg`, `docker.svg`, `moodle.svg`, `nginx.svg`,
`opnsense.svg` and `postgresql.svg` came from the
[Simple Icons collection](https://github.com/simple-icons/simple-icons), whose
[license and trademark notice](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)
apply. `1c.svg` came from the
[Wikimedia Commons 1C logo file](https://commons.wikimedia.org/wiki/File:1C_Company_logo.svg).
The marks identify third-party products; they do not imply affiliation.
